# XO Arena — Android Studio Project

This project wraps the original HTML/JavaScript XO game in an Android WebView.

## Build
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Select `app` as the run configuration.
4. Build > Build Bundle(s) / APK(s) > Build APK(s).

The APK will be under:
`app/build/outputs/apk/debug/`

App name: XO Arena
Application ID: com.example.xoarena
